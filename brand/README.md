# Брендбук Juliette's jewelry 2.0 (черновик)

Визуализация: https://claude.ai/artifact/2msiezpSzZiqJhnLE5JRWH · исходник: `brandbook.template.html`.
Сборка: `python3 -I scripts/build-visual.py brand/brandbook.template.html <imgs.json> <out.html>`.

## Токены (для всех агентов; действуют после согласования владельцем)
| Токен | Цвет | Роль |
|---|---|---|
| coral | `#F28B6E` | Квадрат логотипа, плашки, обложки. Текст на нём — графит |
| coral-deep | `#A84A35` | Ссылки, кнопки с белым текстом, цены |
| powder | `#FBEFEA` | Фон сайта и шаблонов |
| gold | `#C8916F` | Линии и иконки, только декор |
| graphite | `#2E2A2B` | Текст, заголовки, основная кнопка |
| grey | `#6B6365` | Второстепенный текст |

- **Шрифты:** Cormorant Garamond и Cormorant SC (заголовки, гравировочная строка), Manrope (текст и интерфейс).
- **Фирменный элемент:** гравировочная строка. Капитель, точки-разделители, тонкие линии цвета gold.
- **Логотип:** версия 2020 года (квадрат + антиква). Логотип 2019 года (бриллиант + Gabriola) не используется.
