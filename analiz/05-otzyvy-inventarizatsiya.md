## 2. Таблица совпадений с эталонными текстами

- текст переводится в нижний регистр, «ё» заменяется на «е», пунктуация и смайлы `[:...:]` убираются;
- считаются три показателя: SequenceMatcher по словам на весь текст; то же самое с началом эталона той же длины (для отзывов, где есть только начало); доля 6-словных шинглов отзыва, которые есть в эталоне;
- в таблице — наибольший из трёх.

- **GPT-ЯК-N** — N-й по порядку отзыв в чате «2025-03-20_Маркетинг_ювелирных_изделий», начиная с 26.09.2025.
