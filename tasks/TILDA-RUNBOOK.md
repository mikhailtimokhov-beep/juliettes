# Пакет правок в Tilda: выполнить в Chrome владельца

Эти правки владелец согласовал 04.11.2026. Облачная сессия не может управлять Chrome на компьютере владельца, поэтому пакет выполняет **локальная сессия Claude** (приложение Claude Desktop или Claude Code с расширением Claude in Chrome) в Chrome, где владелец уже вошёл в Tilda. Можно сделать и вручную по тем же шагам.

Проект Tilda: juliettes.ru. После каждого пункта — «Опубликовать».

## 1. Открыть страницы для поисковиков (SEO-001)
Для `/about`, `/delivery`, `/kontakti`, `/garantii`, `/payments`, `/gravirovka`: Настройки страницы → SEO → снять «Запретить индексацию страницы поисковыми системами» → Сохранить → Опубликовать.
`/podarochnie-sertificaty` **не трогать**: блок сертификатов переделывается (SITE-005).

## 2. Перенаправление «Пуговки для папы» (SEO-004)
Настройки сайта → Ещё → Редиректы (301): `/pugovki-dlya-papi` → `/pugovki_dlya_pap` → Сохранить → Опубликовать все страницы.

## 3. Дата отзыва (SITE-004)
В блоке отзывов (общий блок или каталог отзывов) у отзыва «Заказывала браслет в честь рождения двойни…» заменить дату `31.06.2026` на `31.05.2026`. Опубликовать страницы, где стоит блок.

## 4. Пометка о Meta рядом с Instagram (SITE-002)
В `/footer` и в блоке «Наш Инстаграм» на главной: рядом со словом или иконкой Instagram поставить `*`, а в подвале добавить строку мелким шрифтом:
> \* Instagram — продукт компании Meta Platforms Inc., деятельность которой запрещена на территории Российской Федерации как экстремистская.

## После выполнения
1. Яндекс Вебмастер → Индексирование → Переобход: `https://juliettes.ru/about`, `/delivery`, `/kontakti`, `/garantii`, `/payments`, `/gravirovka`, `/pugovki_dlya_pap`.
2. Сообщить облачной сессии «правки Tilda выполнены». Она запустит `node scripts/check-site.mjs` и подтвердит результат.

## Не входит в пакет (ждёт решения владельца)
- Новые сниппеты (SEO-003): на согласовании.
- Удаление отзыва «Анна Г.» с сайта (REP-001): ждёт выбора варианта.
- Скрыть текущую страницу сертификатов (SITE-005): ждёт решения.
